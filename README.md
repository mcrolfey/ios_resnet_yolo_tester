# ResnetYoloTester

Bare-metal, benchmark-focused iOS app for a PhD research project measuring
real-world mobile inference constraints (latency, FPS, thermal throttling,
memory) of detecting asbestos in field environments on Apple's Neural
Engine. It toggles between two CoreML/Vision pipelines and logs per-frame
telemetry to a CSV file for offline analysis.

## Setup

1. Install [XcodeGen](https://github.com/yonaskolb/XcodeGen) if you don't
   have it: `brew install xcodegen`.
2. Drop your exported CoreML models into
   `ResnetYoloTester/MLModels/` — see that folder's `README.md` for the
   expected filenames (`YOLOv11nDetector.mlpackage`,
   `ResNetClassifier.mlpackage`).
3. Regenerate the Xcode project after adding models or new source files:
   `xcodegen generate`.
4. Open `ResnetYoloTester.xcodeproj`, set your development team for code
   signing, and run on a physical device (the Neural Engine and camera
   aren't meaningfully testable in Simulator).

`project.yml` is the source of truth for the Xcode project; the generated
`.xcodeproj` is committed for convenience but should be regenerated (not
hand-edited) whenever `project.yml` or the file layout changes.

## Architecture

- **Architecture B (single-stage YOLO)**: `CVPixelBuffer` →
  `VNCoreMLRequest` against the YOLOv11n detector → bounding boxes +
  confidence.
- **Architecture A (multi-stage ROI pipeline)**: same YOLOv11n detector as
  an ROI proposer → each box is cropped out of the original
  `CVPixelBuffer` via CoreImage (`PixelBufferUtilities.crop`) → each crop
  is classified with a second `VNCoreMLRequest` against the ResNet model.

Both pipelines are driven from `CameraManager`'s
`AVCaptureVideoDataOutputSampleBufferDelegate` callback, which runs on a
dedicated background queue so inference never blocks the main thread.
Per-frame latency is measured with `DispatchTime.now().uptimeNanoseconds`
around the `InferenceManager.run(architecture:on:)` call; FPS is derived
from consecutive frame arrival times; thermal state comes from
`ProcessInfo.processInfo.thermalState` (with change notifications
observed); memory comes from `mach_task_basic_info`.

## Telemetry / CSV export

Tap **Start Stress Test** to open a new `benchmark_<unix-timestamp>.csv`
file in the app's Documents directory and begin appending one row per
processed frame:

```
Timestamp,Frame_ID,Architecture,Detections_Count,Latency_ms,FPS,Thermal_State,Memory_MB
```

Writing happens inside the `CSVLogger` actor, so concurrent frame logging
is serialized without blocking the camera/inference pipeline. With
`UIFileSharingEnabled` set (already configured in `project.yml`), CSVs can
be pulled off the device via Finder/USB or the Files app.
